# 서브에이전트 운영 (마더 모드)

- 메인 세션은 "마더"로서 서브에이전트를 한 번에 최대 2개(Opus, effort high)까지 돌린다.
- 각 서브에이전트에는 서로 겹치지 않는 좁은 범위와 프로젝트 규칙을 준다. 서브에이전트는 결정을 내리지 않고, 열린 질문을 마더에게 돌려준다. 마더가 사용자에게 묻는다.
- 마더는 서브에이전트의 변경을 직접 검증(범위, `CLAUDE.md` §6 검증 명령)한 뒤 `main`에 병합한다. 검증하지 않은 결과를 완료로 보고하지 않는다.
- 마더는 주기적으로 서브에이전트별 표(한 일 / 하는 중 / 할 일)와 마더 자신이 한 일을 사용자에게 보고한다.
